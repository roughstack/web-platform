# Support

- Use GitHub Discussions for setup questions and design discussion when
  discussions are enabled.
- Use the issue templates for reproducible bugs and scoped feature requests.
- Use `SECURITY.md` for vulnerabilities; never publish exploit details in an
  issue.

ByteArena is community-maintained software. Support is best effort and does not
include service-level guarantees. Include operating system, runtime versions,
the exact revision, relevant logs with secrets removed, and minimal reproduction
steps when asking for help.
